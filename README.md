# ترند TRend

نظام إدارة الأداء والعمليات لترند: المهام والتواصل والاجتماعات وقياس الإنجاز في مكان واحد،
عربي أولاً. المرجع الأساسي: [كراسة المواصفات الفنية](docs/spec/trend-technical-spec.md).

## البنية

| المسار                 | المحتوى                                                          |
| ---------------------- | ---------------------------------------------------------------- |
| `apps/api`             | خادم NestJS — مونوليث معياري بواجهة `/api/v1` (§5، §8)           |
| `apps/web`             | Next.js (App Router) بالعربية وRTL افتراضياً (§6.1، §10)         |
| `apps/mobile`          | React Native عبر Expo Router (§6.2)                              |
| `packages/db`          | ترحيلات PostgreSQL مع RLS وسجل التدقيق، ومرآة أنواع Drizzle (§7) |
| `packages/permissions` | مصفوفة الأدوار والصلاحيات (§9.1)                                 |
| `packages/schemas`     | مخططات Zod مشتركة بين الويب والجوال والخادم                      |
| `packages/i18n`        | رسائل العربية والإنجليزية وتطبيع النص العربي (§10.2)             |
| `packages/ui`          | رموز التصميم للوضعين الفاتح والداكن (§10.1)                      |

## قواعد المساهمة

- كل تعديل يُربط برمز المتطلب: `FR-<الوحدة>-<رقم>` أو `NFR-<رقم>`.
- لا نص مدمج في الكود: كل نص في `packages/i18n/messages` باللغتين (NFR-14).
- كل جدول جديد يحمل `tenant_id` وتُفعَّل عليه RLS؛ اختبار في `packages/db` يفشل إن نُسي ذلك.
- رسائل الإيداع بصيغة Conventional Commits.

التشغيل المحلي وحالة التنفيذ في [docs/phase-2-foundation.md](docs/phase-2-foundation.md).
